# Island Explorer

A third-person character viewer set on a stylized island. Explore the island, try movement and jump animations, and adjust the world graphics.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Checks

- `npm run test:island` — check island data and world setup
- `npx tsc --noEmit` — check TypeScript
- `npm run lint` — run ESLint
- `npm run build` — build the app

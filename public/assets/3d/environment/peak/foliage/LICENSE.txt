Model research
  Poly Haven CC0 full Fir Tree 01 had a 478,462,204-byte glTF geometry binary
  (https://api.polyhaven.com/files/fir_tree_01); Pine Tree 01 FBX was
  648,483,964 bytes. Not downloaded/executed; rejected as unsuitable for this
  game's 6,800-tree budget. Quaternius Ultimate Nature offers CC0 but is stylized,
  not claimed as realistic. Existing Birch/Maple geometry has actual alpha leaf
  quads and bark/normal maps, but the inspected leaf atlases have flat color and
  the original distant representation is a faceted icosahedron.

Reproduction
  python -I scripts/prepare_peak_foliage.py --out <this-directory>
    --bark-albedo <isolated-source-bark.jpg> --bark-normal <isolated-source-normal.jpg>
  Run from the trusted project, never from a download/extraction directory.
  Requires trusted Pillow and numpy installations. Script has no downloads or
  code evaluation. Manifest contains seed, geometry budgets and output hashes.
